# 🚀 Hao Mei Lai
## 📖 Descripción

HaoMeiLai es el sitio web corporativo de un restaurante de comida china. La plataforma sirve como un escaparate digital para mostrar el menú y realizar la compra para pasar a recoger el pedido. Está alojado en Hostinger para asegurar su disponibilidad en línea.
Proyecto final para la asignatura **Legislación y Derecho Informático**.

## ⚖️ Aspectos de Legislación y Derecho Informático

➤ Protección de Datos
El proyecto recolecta datos personales básicos como nombre e email para poder procesar, confirmar y entregar los pedidos. Esta recolección se alinea con la Ley Federal de Protección de Datos Personales en Posesión de los Particulares (LFPDPPP). Para cumplir, el sitio incluye un Aviso de Privacidad claro donde se informa al cliente qué datos se recolectan, para qué se usan y cómo pueden ejercer sus derechos ARCO.

➤ Propiedad Intelectual
El sitio web utiliza varios elementos protegidos:

Marca: El nombre "HaoMeiLai" y su logotipo se utilizan como una marca ficticia, la cual en un caso real estaría registrada ante el IMPI.

Derechos de Autor: Todas las fotografías del menú, los textos descriptivos y el diseño gráfico de la página son obras protegidas por derechos de autor (Copyright), según la Ley Federal del Derecho de Autor.

Código Fuente: El código PHP, HTML, CSS y JS desarrollado para este proyecto es propiedad intelectual de los integrantes del equipo.

➤ Comercio Electrónico / Contratación
Este proyecto es un claro ejemplo de Comercio Electrónico. Se rige por la Ley Federal de Protección al Consumidor (PROFECO). Para cumplir con la ley, la plataforma:

Muestra precios claros y exactos de cada platillo.

Presenta descripciones detalladas de los productos (menú).

Proporciona un resumen del pedido (un "carrito") antes de la confirmación, permitiendo al usuario verificar su orden.

Al confirmar el pedido, se genera un contrato de compra-venta digital (aunque sea para recoger), por lo que se incluye un enlace a los "Términos y Condiciones" del servicio.

➤ Delitos Informáticos
Para proteger la integridad del sistema y los datos de los clientes, y prevenir delitos tipificados en el Código Penal Federal (como el acceso ilícito a sistemas), el proyecto implementa medidas de seguridad esenciales:

Prevención de Inyección SQL (SQL Injection): Se utilizan consultas preparadas (prepared statements) en PHP (usando PDO o MySQLi) para todas las interacciones con la base de datos, evitando que un atacante pueda manipular las consultas.

Validación de Entradas: Se validan y sanean los datos enviados por el usuario (especialmente en formularios) para prevenir ataques de Cross-Site Scripting (XSS).
